# Мобильная адаптация ветки integration (без изменения функциональности)

Исходная версия: загруженный TerraBitsHackathon-integration.zip.

Изменено:
- добавлен `mobile-compat.css`; стили активны только на экранах до 760 px;
- в `index.html`, `globe.html`, `explore.html`, `terrain.html` добавлено подключение этого CSS.

Не изменено:
- JS-файлы, Python, научные расчёты, данные, 3D-сцена, модели, тексты, логика Sun/Earth visibility и структура desktop UI.
- никаких астронавтов, роверов или first-person функций не добавлено.

Мобильные коррекции:
- перенос навигации и поиска на две строки;
- прокручиваемая панель параметров;
- адаптация графика Solar Elevation, карточек и топографических панелей к ширине телефона;
- перенос элементов управления временем, датой и скоростью в доступную мобильную область;
- минимальные корректировки страниц Atlas, Globe и Terrain.

Проверки:
- `npm test`: 28/28 passed; CSS разобран без ошибок; JavaScript не редактировался.
- Полноценный Playwright browser-test не состоялся: доступ к localhost блокирован средой (`ERR_BLOCKED_BY_ADMINISTRATOR`).
- На настоящем телефоне обязательно проверить открытие Solar Elevation, поиск, параметры и видимость кнопок при раскрытых панелях.

Тестирование на телефоне:
1. Разместить содержимое папки на GitHub Pages как обычный статический сайт.
2. Открыть ссылку в браузере телефона, сделать hard reload/обновить кеш.
3. Проверить ширины 360, 390, 430 px и поворот экрана.
4. Проверить, что Sun/Earth visibility вычисляет те же результаты, что на desktop.

Локально (на ПК): `python tools/serve.py --open`.
Для менее тяжёлого 3D можно попробовать параметр `?detail=light` (предусмотрен самим исходным проектом).
